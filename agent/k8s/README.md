- Secrets are never in these files: the server token and every variable live in OpenBao and are only referenced.

## One-time preparation

```
grauwolf-k8-ops agent add agent
```

(or `grauwolf-k8-ops agent add --harness <harness file>`, which also marks the agent with its owner, the project repository and harness file) makes the namespace, the service account, the OpenBao role and policy and the server token. Do it once per agent, before applying this folder.

## Apply

```
kubectl apply -f k8s/
```

(from the project folder; or let a GitOps tool apply the folder). A new build changes the digest of the image and so rolls the Deployment out.
